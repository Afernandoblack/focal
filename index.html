Phone එකෙන් සහ PC එකෙන් එකවර සම්බන්ධ වීමට:

  1. console.firebase.google.com වෙත ගොස් ඔබේ Firebase Project එක තෝරන්න.
  2. Cloud Firestore Database එකක් ආරම්භ කරන්න.
  3. Authentication > Sign-in method හි Email/Password සක්‍රිය කර ඔබේ පරිශීලක ගිණුම සාදන්න.
  4. Project Settings > General > Your Apps වෙතින් ලබාගන්නා firebaseConfig JSON කේතය පහත paste කරන්න.
  5. Firestore Rules හි පහත path එක සහ ඔබේ Firebase පරිශීලක UID එක භාවිතා කරන්න:
match /artifacts/floor-paint-pro/public/data/painting_jobs/{jobId} {
  allow read, write: if request.auth != null
    && request.auth.uid == "YOUR_USER_UID";
}

YOUR_USER_UID වෙනුවට Authentication > Users හි ඔබේ UID එක යොදන්න. Firebase Console හි Firestore Rules වෙත මෙය ඇතුළත් කර Publish කරන්න.

Google Cloud Console හි Calendar API සක්‍රිය කර OAuth Web Client ID එකක් සාදන්න. මෙම app එක localhost web server එකකින් විවෘත කළ යුතුය; file:// URL එකකින් OAuth ක්‍රියා නොකරයි.
